# Personal Portfolio

This website itself! A minimalist, wireframe-inspired portfolio and interactive project hub designed to showcase web applications, client work, and code experiments.

## Design Philosophy
- **Wireframe Aesthetic**: Clean 1px high-contrast structural grid lines, monospace typography, and bracketed UI indicators.
- **Controlled Palette**: Pure black (`#000000`), crisp white (`#ffffff`), and Medium Slate Blue (`#7b68ee`) accent highlights.
- **Fast & Zero-Bloat**: Built without heavy frontend framework runtimes, delivering near-instant page transitions and lightweight assets.

## Key Features
- **Astro Content Layer**: Strictly typed Markdown schemas for projects and technical blog posts.
- **Real-Time Search & Filtering**: Instant client-side search across titles, descriptions, and tags with simultaneous category toggles.
- **Dynamic Routing**: Automatic generation of dedicated project pages via `[...slug].astro`.
- **Cloudflare Deployment**: Static asset deployment optimized for low-latency global delivery.
