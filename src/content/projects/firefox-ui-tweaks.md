# Firefox UI Tweaks

A collection of custom `userChrome.css` and `userContent.css` stylesheets engineered to strip browser clutter, optimize screen real estate, and introduce bespoke tab animations.

## Key Improvements
- **Auto-hiding Sidebars**: Clean collapse mechanisms for vertical tab trees.
- **Compact URL Bar**: Streamlined address bar with contextual action buttons.
- **Dark Mode Harmony**: Matching systemic dark theme tokens across web content.
