# Chrome Dino Game Clone

A faithful reproduction of the classic offline T-Rex runner built using vanilla JavaScript and HTML5 Canvas.

## Highlights
- **Frame-perfect Physics**: Custom jump curves and duck mechanics.
- **Dynamic Difficulty**: Increasing obstacle speed and night-mode day/night cycles.
- **Hi-score Local Persistence**: Saves your record across browser sessions.
