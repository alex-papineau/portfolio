# Conway's Game of Life

A browser-based implementation of the classic zero-player game created by mathematician John Conway.

## Cellular Rules
1. **Survival**: Any live cell with 2 or 3 live neighbors stays alive.
2. **Death**: Any live cell with fewer than 2 neighbors dies (underpopulation) or with more than 3 dies (overpopulation).
3. **Birth**: Any dead cell with exactly 3 live neighbors becomes a live cell (reproduction).
