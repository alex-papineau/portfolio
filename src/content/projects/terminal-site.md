# Terminal Site

An experimental web experience built to mimic a Unix terminal environment right in the browser.

## Features
- **Built-in Shell Interpreter**: Supports commands like `help`, `about`, `projects`, `cat`, `clear`, and `sudo`.
- **Command History**: Navigate previous commands with Up/Down arrow keys.
- **Custom Color Schemes**: Switch between Amber, Green CRT, and Matrix color themes.
