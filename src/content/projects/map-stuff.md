# Map Explorer

An interactive geospatial mapping visualization powered by Leaflet.js, OpenStreetMap data, and CARTO dark tiles.

## Capabilities
- **Geographic Plotting**: Custom coordinates and interactive marker popups.
- **Routing & Navigation**: Real-time waypoint computation and geocoding.
- **Dark Map Theme**: High-contrast tile aesthetic matching the site styling.
