# Map Explorer

Interactive geospatial mapping and visualization built with Leaflet.js, featuring dark-mode Carto tiles, custom interactive markers, and fluid coordinate inspection.

## Features
- **Dark Mode Carto Tiles**: Seamless aesthetic integration with dark terminal styling.
- **Dynamic Viewport Centering**: Smooth zoom controls and pan animations.
- **Interactive Geospatial Popups**: Contextual metadata cards bound to geographic coordinates.
