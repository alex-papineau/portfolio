# Twitter Turn-Based Post Theme Plugin

A browser plugin that overlays RPG-style turn-based combat mechanics and retro dialogue boxes over social media posts and reply threads.

## Mechanics
- **Post Battles**: Replies turn into round-robin turn choices (`Attack`, `Defend`, `Quote`, `Flee`).
- **HP Gauges**: Like-count and retweet ratios dynamically influence character stats.
- **Custom Sprite Overlays**: 8-bit retro avatars replacing profile pictures.
