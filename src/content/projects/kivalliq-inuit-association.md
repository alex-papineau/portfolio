# Kivalliq Inuit Association (KIA)

Official website for the Kivalliq Inuit Association, which serves Inuit in seven Nunavut communities: Arviat, Baker Lake, Chesterfield Inlet, Coral Harbour, Naujaat, Rankin Inlet, and Whale Cove.

## How it's built

The custom WordPress theme loads fast and uses little data, since internet bandwidth varies a lot across northern communities. Dynamic ACF sections handle departmental directories, community announcements, tender notices, and career opportunities. Administrative staff across departments can post regional news, update job boards, and organize PDF documents without developer help. Navigation follows what beneficiaries need to find: land administration forms, cultural resources, and community program guidelines.
