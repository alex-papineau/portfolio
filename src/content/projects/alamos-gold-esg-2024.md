# Alamos Gold 2024 ESG Report

Custom WordPress site for Alamos Gold's 2024 Environmental, Social, and Governance (ESG) report, with interactive performance metrics and sustainability disclosures.

## How it's built

The theme is custom, built from scratch with modular PHP templates for speed and clean markup. Advanced Custom Fields splits the report into custom built WordPress blocks with modular data and layouts populating the blocks. Alamos Gold's team can update disclosures, swap downloadable PDFs and spreadsheets, and reorganize pages from the WordPress dashboard. chart.js is used for the various data tables on the site.
